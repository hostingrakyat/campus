# Mahasigma Simulator · Sigma College Student Simulator

Game simulasi kehidupan mahasiswa Indonesia (3D low-poly vinyl, Android) — bertahan dari dosen yang ghosting, birokrasi kampus, UKT, dan kerja part-time sampai lulus (atau tidak).

| | |
|---|---|
| Engine | Godot 4.7 (GDScript, renderer GL Compatibility) |
| Platform | Android (arm64-v8a + armeabi-v7a), portrait |
| Bahasa | Bahasa Indonesia + English, mode dual subtitle |
| Monetisasi | Koin (soft) + Diamond (hard) · Shop (IAP) · AdMob rewarded/interstitial (mock di build sampel) |

- `game/` — project Godot ([cara build & test](game/README.md))
- `docs/GDD.md` — desain game (loop, stat, ekonomi, ending)
- `docs/MONETIZATION.md` — cara mengganti mock iklan/IAP dengan AdMob & Google Play Billing asli
- `docs/GAME_PLAN.md` — riset awal (keluhan mahasiswa, engine, ide judul)
